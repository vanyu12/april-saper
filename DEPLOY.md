# Деплой: Bothost + Neon (бесплатно, база не слетает)

Схема: код лежит в публичном репозитории GitHub, бот крутится на Bothost (тариф
Starter, 0 ₽), а данные — в бесплатном Postgres Neon. Перезапуск контейнера
больше не обнуляет балансы: они в Neon.

Нужны три аккаунта: **Neon**, **GitHub**, **Bothost**. В каждом — подтверждение
почты и капча, поэтому регистрацию делает владелец почты.

## 1. Neon (база)

1. neon.tech → Sign up (можно через Google/GitHub).
2. Create project → регион Europe (Frankfurt).
3. На странице проекта нажми **Connect** и скопируй строку вида:
   ```
   postgresql://user:pass@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```
4. Сохрани её — это `DATABASE_URL`. Таблицы создадутся сами при первом запуске.

## 2. GitHub (код)

1. github.com → New repository → имя `april-saper`, **Public**.
2. Add file → Upload files → перетащи содержимое папки `april-saper`
   (не саму папку, а файлы внутри; `.env` загружать не нужно).
3. Commit changes.

Если удобнее из архива: распакуй `dist/april-saper.zip` и загрузи всё его содержимое.

## 3. Bothost (хостинг)

1. bothost.ru → Регистрация.
2. «Добавить бота» → платформа Telegram → укажи токен от BotFather →
   Git URL репозитория (кнопка Code → HTTPS → ссылка вида
   `https://github.com/логин/april-saper.git`).
3. Язык — Python, главный файл — `main.py` (есть `bothost.json`, подхватится сам).
4. В настройках бота → «Переменные окружения» добавь:
   - `BOT_TOKEN` — токен бота;
   - `DATABASE_URL` — строка из Neon;
   - `PUBLIC_URL` — пока пусто, заполним после домена.
5. Включи «Использовать домен» → получишь адрес вида
   `https://bot-xxxx-user.bothost.tech`. Скопируй его в `PUBLIC_URL`.
6. Пересобери/перезапусти бота.

## 4. Проверка

- В Telegram: `/start` — бот должен ответить приветствием и кнопкой «Играть».
- Открой `PUBLIC_URL` в браузере — должна загрузиться игра.
- Сыграй раунд, затем перезапусти бота в панели Bothost и снова открой профиль:
  баланс должен сохраниться (значит, работает Neon).

## Если что-то не так

- **Бот не отвечает** — смотри логи в панели; чаще всего неверный `BOT_TOKEN`
  или не подхватился `main.py`.
- **502 / белый экран Mini App** — проверь, что `PUBLIC_URL` совпадает с доменом
  и бот слушает порт из переменной `PORT` (это уже сделано в коде).
- **Баланс обнулился после перезапуска** — не задан `DATABASE_URL`, бот пишет
  в SQLite внутри контейнера.
- **`pgserver` в тестах** — локальная зависимость для проверки, на хостинге не нужна.

## Вариант без GitHub и Neon: Bothost Basic, 99 ₽/мес

1. Оформить тариф Basic.
2. Профиль → «Интерфейс» → включить «Загрузка бота из архива».
3. «Мои боты» → «Загрузить из архива» → `dist/april-saper.zip`.
4. Токен, язык Python, главный файл `main.py` → «Задеплоить».
5. В переменных: `BOT_TOKEN`, `PUBLIC_URL` (после выдачи домена).
6. База будет на постоянном диске Bothost, `DATABASE_URL` не нужен.
