# Апрельский сапёр

Telegram-бот с Mini App в стиле «Мины»: поле 5×5, от 1 до 24 мин, растущий множитель
и кнопка «Забрать». Вся экономика — на виртуальных «сапах»: без депозитов, ставок
на реальные деньги и вывода средств.

## Что уже готово

- **Mini App**: поле 5×5, анимации открытия и взрыва, настройка ставки (½ / 2× / MAX),
  выбор мин чипами и слайдером, подсказка «шанс следующей клетки».
- **Честная раскладка**: позиции мин выводятся из `HMAC-SHA256(server_seed,
  client_seed:nonce:i)`, до раунда показывается хеш серверного seed, в разделе
  «Честность» можно сменить seed и увидеть предыдущий целиком.
- **Прогресс**: баланс, статистика, достижения, история раундов, два лидерборда
  (по балансу и по лучшему множителю), реферальная ссылка.
- **Бонусы**: 1000 сапов на старте, 500 раз в сутки, 500 за друга после его 5 партий.
- **Бот**: `/start`, `/play`, `/balance`, `/ref`, `/fair`, `/help`, кнопка меню WebApp.

## Быстрый старт

1. **Зависимости** (Python 3.12 уже установлен):

   ```powershell
   python -m pip install -r requirements.txt
   ```

   Если `python` не находится, перезапусти терминал или используй
   `& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe"`.

2. **Настройки**: скопируй `.env.example` в `.env` и заполни:

   ```ini
   BOT_TOKEN=123456:токен-из-BotFather
   PUBLIC_URL=https://ваш-домен
   ```

3. **Бот в BotFather**: `/newbot` → имя «Апрельский сапёр» → юзернейм
   (например `AprilSaperBot`). Токен — в `BOT_TOKEN`.

4. **HTTPS обязателен**: Telegram открывает Mini App только по `https://`.
   Для локальной проверки подойдёт временный туннель:

   ```powershell
   cloudflared tunnel --url http://localhost:8080
   ```

   Полученный адрес вида `https://xxx.trycloudflare.com` впиши в `PUBLIC_URL`
   и перезапусти бота. Для постоянной работы — VPS с доменом и Caddy/Nginx.

5. **Запуск**:

   ```powershell
   python main.py
   ```

   При старте бот сам ставит кнопку меню «Играть» со ссылкой на `PUBLIC_URL`.

## Локальная отладка интерфейса

```powershell
python run_dev.py
```

Открой `http://127.0.0.1:8080/` в браузере: API работает без Telegram,
пользователь — `DEV_USER_ID`. В `.env` для этого выставляется `DEV_MODE=1`.

> `DEV_MODE=1` нельзя оставлять на публичном сервере: API начнёт пускать
> запросы без проверки Telegram.

## Проверка

```powershell
python tests\smoke_test.py
```

Проверяются: таблица множителей, детерминированность и проверяемость мин,
старт/открытие/кэшаут, сгорание ставки, защита от отрицательного баланса,
дневной бонус, история, лидерборд, смена seed.

Скриншоты мобильной вёрстки (нужен запущенный `run_dev.py`):

```powershell
python tests\screenshots.py
```

## Механика

- Шанс пройти `k` клеток при `m` минах: `P(k) = C(25−m, k) / C(25, k)`.
- Множитель: `M(k) = 0,99 / P(k)`, округление вниз до сотых.
- При 3 минах: 1 клетка — ×1,12, 5 — ×2,00, 10 — ×5,00, 15 — ×18,97,
  19 — ×113,85, полное поле — около ×2277.
- Матожидание любого кэшаута одинаково (RTP 99%): число мин и момент остановки
  меняют только дисперсию.

Лимиты: ставка 10–100 000 сапов, мин 1–24, одна активная игра на пользователя,
задержка между кликами 80 мс.

## База данных: SQLite или Postgres

По умолчанию используется SQLite (`data/saper.db`). Если задать `DATABASE_URL`,
бот автоматически переключится на Postgres — это нужно на бесплатных хостингах,
где диск контейнера очищается при перезапуске.

Neon (бесплатный Postgres, без карты):

1. Зарегистрируйся на neon.tech и создай проект.
2. Скопируй строку подключения вида
   `postgresql://user:password@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`.
3. Впиши её в переменную окружения `DATABASE_URL` на хостинге.
4. Таблицы создаются автоматически при первом запуске.

SQLite-путь и Postgres-путь проверяются тестами: `tests/smoke_test.py` и
`tests/pg_test.py` (второй поднимает локальный Postgres через пакет `pgserver`).

## Честность (provably fair)

1. У пользователя есть серверный seed и его SHA-256-хеш (виден заранее).
2. Номер раунда (`nonce`) увеличивается на каждом старте.
3. Позиции мин — детерминированная перестановка на HMAC-потоке от
   `server_seed`, `client_seed` и `nonce`.
4. После смены seed серверный seed раскрывается: можно пересчитать хеш и
   убедиться, что раскладка восстановима.
5. `POST /api/fairness/verify` с `round_id` проверяет любой завершённый раунд.

## Деплой на VPS (кратко)

`systemd`-юнит:

```ini
[Unit]
Description=April Saper bot
After=network.target

[Service]
WorkingDirectory=/opt/april-saper
ExecStart=/opt/april-saper/.venv/bin/python main.py
Restart=always
EnvironmentFile=/opt/april-saper/.env

[Install]
WantedBy=multi-user.target
```

Caddy перед приложением:

```
saper.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

## Правовой момент

Это развлекательная игра на виртуальные баллы. Реальные деньги не принимаются,
не выводятся и не конвертируются. Не превращайте проект в онлайн-казино:
в РФ интернет-гемблинг запрещён (244-ФЗ), а Telegram удаляет такие приложения
по своим правилам. Монетизация — реклама, подписка или Stars за косметику,
но не за ставки.
